# Frivo 1.4.2

## Typing dots in VRChat while you respond

While you're putting a reply together, VRChat now shows the typing dots over your head, the same way its own keyboard does, so the person you're talking to knows an answer is coming.

- The dots come up when you start talking with dictation on, or when you type in the message box.
- They go away when the reply is sent, when you clear the box, or when a draft has sat untouched for a few seconds.
- They only appear when the **Chatbox** switch is on and FrivOSC is connected.
- To turn them off: Settings > VRChat > **Show typing while I respond**.

**Requires FrivOSC 1.2.0** on your VRChat PC. Older versions of FrivOSC keep working, just without the dots.

## Frivo starts again after an in-app update

Updating from the browser stopped Frivo but sometimes left it stopped, so it had to be started again by hand on the Frivo PC.

- If Frivo isn't running again 20 seconds after an update installs, the updater now starts it itself, as the person who asked for the update, in their own Windows session.
- The helper that normally restarts Frivo now starts more reliably.

This takes effect from the next update onward. The copy of Frivo you're updating from is the one that runs the update, so installing 1.4.2 itself may still leave Frivo stopped once. If it does, start Frivo from the Start menu on the Frivo PC.
