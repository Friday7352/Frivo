            The marker is the gate; the bar is the current level. Set it just above
            background chatter — in VRChat, volume tracks distance, so the loudest
            voice is normally whoever you're facing.
          

        


        

          
          
          

            A line is normally finished when the speaker pauses. When nobody pauses —
            people answering over each other — this commits anyway so text keeps
            flowing. Shorter values respond faster but split sentences more often.
          

        


        

          
          

            Off, each line appears once the person stops speaking. On, it updates roughly
            every second and corrects itself as more of the sentence arrives. Speaker
            labels are still worked out from the finished sentence either way.
          

        


        

          
          

            
            0.65
          

          

            Lower it if one person keeps getting split into several speakers. Raise it if
            two different people get merged into one. Applies immediately.

                  Runs on this server when you click the offline status chip. Leave blank to
                  disable. Needs the scheduled task installed on the other machine
                  (install_whisper_task.ps1) and its remote-management firewall rule enabled.
                


                
                

                  
                  
                

                
Test the connection first to load the model list.

              

            

          


          

            

              

                
                

                  
                  
                  
                

                

                  The LAN address of whichever machine runs VRChat — 127.0.0.1 if that's this
                  server. Leave blank to disable. VRChat listens on UDP 9000 by default, so
                  that PC needs an inbound rule for it:
                  netsh advfirewall firewall add rule name="VRChat OSC" dir=in action=allow protocol=UDP localport=9000
                

              

            

            

              The reply appears in your chatbox word for word — the moment playback starts
              if Speak is on, immediately if it isn't. Anything over 144 characters is sent
              as pages; keep the reply-length fader near 25 words to land in one. Delivery
              can't be confirmed: OSC is UDP, so nothing comes back either way.
            

          


          

            

              

                
                

                  
                  
                

                

                  With the voice playing, the text is a caption and should keep pace with it.
                  With it off the text is the whole message and has to be read, which takes
                  longer. Only affects replies long enough to need more than one page.
