    Phones warn that Frivo's connection isn't private, because Frivo makes its own certificate. Install it on your phone once and the warning goes away. Only do this for your own Frivo.

      2. 
                      
    2. Open Settings › General › VPN & Device Management, tap Frivo Local CA, and Install.
      3. 
                      
    3. Open Settings › General › About › Certificate Trust Settings and turn on Frivo Local CA.
      4.

                  Moved Frivo and lost everything?
                  
    Your old data is still on the old PC, unless Frivo was uninstalled with its data. Find the folder there with config.json, profiles.json and a saved folder in it:
    
                  
      
                    
    • If Frivo ran from a folder you put it in (like C:\Frivo), it's app inside that folder.
      • 
                    
    • If it was installed, it's %APPDATA%\Frivo: paste that into the File Explorer address bar.
      • 
                  
    
                  
    Right-click the folder, Send to › Compressed (zipped) folder, and restore that zip here. Or open the old Frivo, download a backup, and restore that.
    
                  
    Favourite voices and your tags are kept in the browser, for each address Frivo is opened at. They come across with a backup made in the browser you used with the old address.

                  Get a key ↗
                
    
                
                
    
                
    
                  Only needed for ElevenLabs voices. Stored on this server in config.json and
                  only ever sent to ElevenLabs. Paste a new one to replace it. The voice itself is
                  chosen from the chip above the message box, per profile.
                
    
              
    
            
    

            
            
    How to get your key
    
            
    
              
      
                
    1. 
                  Sign in to ElevenLabs
                  At elevenlabs.io. A free account works; paid plans get more credits and the better voices.
                
      2. 
                
    2. 
                  Open API keys
                  Go straight to Settings › API keys. If ElevenLabs moves it, look for API keys under your account or developer settings.
                
      3. 
                
    3. 
                  Create a key
                  Click Create API key and name it something like Frivo. Leave its expiry on Never, or Frivo stops speaking when it runs out.
                
      4. 
                
    4. 
                  If you restrict what it can do
                  Frivo needs Text to Speech, Voices (read, and write if you want to remove voices from your library here) and User (read, for the credits left). You can also set a credit limit for the key.
                
      5. 
                
    5. 
                  Copy it, and paste it above
                  ElevenLabs shows the key once only, so copy it before closing the window. It starts with sk_. Paste it into the box above and press Save key (top of Settings).
                
      6. 
              
    
              
    
                Lost it, or think someone else has it? Delete it on the same page and make a new one.
                Once the key works, Frivo lists your ElevenLabs voices and shows your credits left.
