Set up local AI

Let a graphics card on your own PC write Frivo's replies, instead of OpenAI. It's free, nothing leaves your home network, and on a decent graphics card it's about as quick. It takes about 15 minutes, and every command is ready to copy.

First, two questions

Which PC will run the AI?

Pick the PC with the best graphics card. Do every step below on that PC, except the last one.

Not sure? On that PC, open Task Manager (Ctrl + Shift + Esc) → Performance → GPU, and look at Dedicated GPU memory: it's the number after the slash, like 0.0/8.0 GB.

Your three models

Frivo lets you switch between these with the AI chip above the message box.

1Update the graphics driver

The AI runs on the graphics card, and an old driver is the most common reason it doesn't.

  • NVIDIA: open the NVIDIA app (or GeForce Experience) and install the latest driver, or get it from nvidia.com/drivers.
  • AMD: use AMD Software: Adrenalin Edition. Recent Radeon cards (RX 6000 and newer) are supported.

Restart the PC if the driver installer asks you to.

2Install Ollama

  1. Go to ollama.com/download, choose Windows, and download OllamaSetup.exe.
  2. Run it and click through the installer.
  3. When it finishes, an Ollama window may open. You won't need it, so you can close it. Ollama keeps running in the background (its icon is near the clock).

If something isn't right

    

      "ollama" isn't recognized
      
PowerShell windows opened before Ollama was installed don't know about it. Close PowerShell, open a new one, and try again.

    

    

      Test says nothing is listening, or it can't connect
      
    
        
  • Check Ollama is running: its icon should be near the clock. If not, start Ollama from the Start menu.
    • 
        
  • On Frivo's PC, open http://<the address>:11434 in a browser. It should say Ollama is running.
          If it doesn't load, redo step 4 and check the network is Private.
    • 
        
  • Make sure the address starts with http:// (not https) and ends with :11434.
    • 
      

    

    

      Other PCs can't connect (it shows 127.0.0.1:11434)
      
Ollama started without the settings from step 3. Run step 3 again. If it still shows 127.0.0.1, open the Ollama
        window (from the Start menu), click the sidebar icon at the top left, then Settings, turn on
        Expose Ollama to the network, and run step 3 once more.

    

    

      UNTIL says "4 minutes from now", not about an hour
      
The same cause: run step 3 again. (Frivo also tells Ollama how long to keep the model loaded, so replies from Frivo stay quick either way.
        That's set in Frivo under Settings › Providers › Free the graphics card when idle: an hour unless you change it.)

    

    

      PROCESSOR shows a split, like "30%/70% CPU/GPU"
      
The model doesn't fit in the graphics card's memory, so part of it runs on the processor, which is much slower.
        Use a smaller model: pick Balanced or Fast with the AI chip, close other programs using the graphics card
        (such as games), or tick Evora also uses this graphics card above if it does, and download the models it suggests.

    

    

      Frivo says a model "isn't on the Ollama PC yet"
      
That model hasn't been downloaded. Run the command it shows (ollama pull …) on the Ollama PC, or redo step 5.

    

    

      Replies aren't as good as with OpenAI
      
Smaller models are quicker but less careful, especially with Clean up, which has strict rules. Try Balanced
        or Best with the AI chip. You can switch back to OpenAI any time in Settings → Providers → Chat replies.

    

    

      How do I know replies come from my PC?
      
Hover over a reply in Frivo: the line underneath says Local for your own AI, or OpenAI.
        To be strict about it, turn off Fall back to OpenAI if a local service is down in Settings → Providers;
        then Frivo shows an error instead of quietly using OpenAI.
